# HVAC A2L Field Checklist (Educational)

Python **stdlib-only** guided checklist for R-454B / R-32 / A2L service and install (pre-job, brazing, weigh-in charge, RDS/mitigation reminders, cylinder notes).

> **Educational only — not code or legal advice.**  
> Follow OEM literature and your AHJ.

## Quick start

```bash
cd hvac-a2l-field-checklist
python3 a2l_checklist.py --help
python3 a2l_checklist.py -i
python3 a2l_checklist.py --refrigerant R-454B --job service
```
